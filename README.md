# Trafalgar Healthcare Landing Page

A responsive healthcare landing page built with React and Tailwind CSS, based on the provided Trafalgar Figma design reference. 

Live Link : 
https://trafalgar-landing-page.vercel.app/

## 📌 Project Overview

This project is a frontend implementation of the Trafalgar healthcare landing page.

The goal was to recreate the provided Figma design as closely as possible while maintaining a clean, responsive, and reusable React component structure.

The page is designed to work across:

- 📱 Mobile
- 📱 Tablet
- 💻 Desktop

---

## ✨ Features

- Responsive navigation
- Mobile hamburger menu
- Hero section with healthcare illustration
- Healthcare services section
- Service cards
- Leading healthcare providers section
- Mobile application section
- Customer testimonials
- Latest articles section
- Responsive footer
- Smooth scrolling navigation
- Hover interactions
- Responsive layouts using Tailwind CSS

---

## 🛠️ Technologies Used

- React
- Vite
- Tailwind CSS
- JavaScript (ES6+)
- HTML5
